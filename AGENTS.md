# About project

## Shopping Website Clone

- Frontend supports two base level routes
  - '/' - customer/end user level routes.
  - '/system' - backoffice level routes.
- E.g. registration for backoffice level looks like /system/registration. for customers it looks like /registration.

# Guidelines

## Development Guidlines

- Do Test Driven Development
- Target max lines in each file to be 120.
- Follow SOLID principles.
- Add docstrings.
- Do not make assumptions. Ask clarifying questions.
- Run tests and security checks after development and make sure the checks PASS.
- Create proper constants and use them. No magic numbers/strings.
