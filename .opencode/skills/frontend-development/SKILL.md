## When to use

- Use this skill to work only on frontend tasks.

## When not to use

- Do not use this skill to work on backend tasks.

## Conventions and Guidelines

### General Frontend Development Guidelines

- Follow the standard next js frontend architecture.
- Follow ATOMIC component architecture.

### State management

- Use react-query for sever states.
- Use zustand for app state.

### Styling

- Use tailwind for styling and theming
